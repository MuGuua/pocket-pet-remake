# 后台前端骨架

该目录用于承载 Pocket Pet 的 Web 管理后台。

## 当前状态

- 已初始化 React + TypeScript + Vite 工程骨架
- 已接入真实管理员登录、登录态校验、玩家 CRUD 接口
- 已接入宠物 CRUD 接口，并补了对应后台管理页
- 已接入背包 CRUD 接口，并补了对应后台管理页
- 已接入任务模板 CRUD 与玩家任务进度 CRUD，并补了统一任务管理页
- 已接入 NPC / 场景实体配置与 NPC 菜单配置 CRUD
- 玩家管理页当前支持筛选、分页、详情、新增、编辑、删除
- 宠物管理页当前支持筛选、分页、详情、新增、编辑、删除
- 背包管理页当前支持筛选、分页、详情、新增、编辑、删除
- 任务管理页当前支持模板管理与玩家任务进度管理两套 CRUD
- NPC 配置页当前支持世界实体分布与 NPC 菜单动作两套 CRUD
- 页面已按 SkillHub 安装的 `ant-design-skill` 模式重写为 Ant Design CRUD 管理台
- 已验证 `npm run build` 可通过
