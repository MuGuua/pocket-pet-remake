战斗系统规则

1. 基础属性

属性| 上限| 说明
生命| 150万| 当前/最大生命；当前生命降至0时死亡。
攻击| 25万| 普攻主要伤害来源，也可参与技能计算。
防御| 25万| 抵消受到的直接伤害。
速度| 3万| 决定行动顺序，也可参与技能计算。
法力| 50万| 魔法类技能主要伤害来源。
暴击率| 150| 决定触发暴击的概率。
暴击伤害| 2000%| 暴击时的伤害倍率，基础最低爆伤为150%。

---

2. 控制抗性

属性| 上限
抗封印| 400
抗昏睡| 400
抗混乱| 400
抗麻痹| 400
抗诅咒| 400

控制判定

技能控制效果具有对应的控制威力。

目标对应抗性 > 控制威力 → 免疫该控制。

否则控制正常生效。

各类控制抗性独立计算，仅抵抗对应控制。

---

3. 特殊抗性

抗爆伤

上限：1000%

仅在受到暴击时生效，降低攻击者对自己的实际爆伤，不影响队友。

实际爆伤 = MAX（攻击者爆伤 - 目标抗爆伤，150%）

最低爆伤固定为 150%，无法继续降低。

---

物理抗性

上限：150

降低受到的普通攻击伤害。

技能抗性

上限：150

降低受到的技能伤害。

物理抗性（逆）

上限：100

无视目标一定数值的物理抗性。

有效物理抗性 = MAX（目标物理抗性 - 攻击者物理抗性〔逆〕，0）

技能抗性（逆）

上限：100

无视目标一定数值的技能抗性。

有效技能抗性 = MAX（目标技能抗性 - 攻击者技能抗性〔逆〕，0）

逆抗性规则

逆抗性不得直接扣除目标面板抗性，必须针对每个攻击者独立计算。

例：

目标物理抗性150：

- A物理抗性（逆）100 → 对A有效物抗50
- B物理抗性（逆）80 → 对B有效物抗70

即：

攻击者 → 目标 → 单独计算有效抗性

---

4. 命中与闪避

属性| 上限| 说明
命中| 250| 提高攻击命中概率。
闪避| 200| 降低敌方攻击命中概率。

命中判定

命中率 = 攻击者命中 - 目标闪避

命中率超过100%时按 100% 计算。

必中技能无视命中与闪避，必定命中。

---

5. 伤害计算

普通攻击

普攻伤害 = [(攻击 × 暴击倍率 × (1 + 增伤)) - 目标防御] × (1 - 目标减伤)

技能攻击

技能伤害 = [(技能综合伤害 × 暴击倍率 × (1 + 增伤)) - 目标防御] × (1 - 目标减伤)

技能综合伤害由具体技能公式决定，可包含攻击、法力、速度、固定伤害及技能倍率等。

暴击

未暴击：

暴击倍率 = 1

暴击：

暴击倍率 = 实际爆伤 ÷ 100%

目标存在抗爆伤时，先计算抗爆伤，再得到实际暴击倍率。

增伤/减伤叠加

多个增伤或减伤效果不直接相加，而是各自作为独立系数相乘。

例如：

20%减伤 + 30%减伤：

最终系数 = 0.8 × 0.7 = 0.56

即最终受到 56%伤害。

最低伤害

计算结果≤0时：

最终伤害 = 0

不会产生负伤害。

---

6. 控制效果

封印

无法使用技能，但可以普攻和使用药品。

昏睡

无法行动；受到攻击后解除昏睡。

混乱

普攻及攻击技能的目标转为己方单位。

麻痹

以下属性降低 50%：

- 物理抗性
- 技能抗性
- 抗爆伤
- 命中
- 闪避

麻痹后属性 = 原有效属性 × 50%

诅咒

根据具体技能产生持续负面效果，例如：

- 持续伤害/流血
- 每回合损失生命
- 降低治疗效果
- 禁止回血

具体效果及持续时间由施加诅咒的技能决定。

---

7. 战斗结算顺序

统一按以下顺序处理：

行动判定 → 目标判定 → 命中判定 → 暴击判定 → 抗爆伤 → 基础伤害 → 防御 → 物理/技能抗性及逆抗性 → 其他增减伤 → 最终伤害 → 扣除生命 → 受击效果 → 死亡判定

其中：

- 普攻使用物理抗性
- 技能使用技能抗性
- 必中技能跳过命中判定
- 未暴击时爆伤倍率固定为1
- 逆抗性针对每个攻击者独立计算
- 最终伤害最低为0

---

8. 核心公式

控制免疫：
"对应抗性 > 控制威力"

有效物抗：
"MAX(目标物抗 - 攻击者逆物抗, 0)"

有效技抗：
"MAX(目标技抗 - 攻击者逆技抗, 0)"

实际爆伤：
"MAX(攻击者爆伤 - 目标抗爆伤, 150%)"

命中率：
"MIN(攻击者命中 - 目标闪避, 100%)"

最终伤害：
"MAX(计算伤害, 0)"

---

9. 核心原则

1. 基础属性与临时属性分离：BUFF、DEBUFF、麻痹、逆抗性等不得错误修改角色永久面板。
2. 每个目标独立结算：攻击者、目标、抗性、逆抗性均按本次攻击单独计算。
3. 技能负责提供伤害参数，战斗系统统一处理命中、暴击、防御、抗性及增减伤。
4. 百分比在程序内部建议统一使用倍率计算，如150%=1.5、20%增伤=1.2、30%减伤=0.7。
