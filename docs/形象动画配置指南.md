# 形象动画配置指南

本文说明 `UnitSkin`（`.tres`）中 **CHJ + PNG 局部覆盖** 的完整规则、动画帧新建流程，以及每个参数的用法与示例。

相关文档：

- CHJ 二进制格式：`docs/chj_sprite_web_control.md`
- 架构方案：`docs/chj_character_visual_plan.md`
- 资源脚本：`client/scripts/feature/battle/resources/unit_skin.gd`

---

## 1. 核心概念

### 1.1 两种动画来源

| 来源 | 文件 | 负责内容 |
| --- | --- | --- |
| **CHJ** | `client/asset/chj/*.chj` | 世界 idle/walk、战斗待机（末两组）、技能（独立 CHJ 第 0 组） |
| **PNG SpriteFrames** | 内嵌于 `UnitSkin.sprite_frames` | 按需**局部替换** CHJ 中不满意的动画 |

### 1.2 三种渲染模式

```text
有 chj_path 且加载成功？
  ├─ 是 → CHJ 基础模式（可与 sprite_frames 局部覆盖并存）
  └─ 否 → 有 sprite_frames？
            ├─ 是 → 纯 PNG 模式（整皮 AnimatedSprite2D）
            └─ 否 → 加载失败，player 回退 Legacy
```

### 1.3 局部覆盖总规则

同时满足以下两点，才会用 PNG 替换 CHJ 的**当前这一条**动画：

1. `sprite_frames` 里**存在**该动画名（`has_animation` 为 true）
2. 映射表里**指名**了这条动画（见下文各场景的映射字段）

未指名、或 `sprite_frames` 里没有的动画，**一律继续走 CHJ**（或纯 PNG 模式下的原有逻辑）。

状态切换时自动恢复：例如战斗待机用 PNG，开始走路后切回 CHJ walk 组。

## 2. 动画解析规则（按场景）

### 2.1 主世界 `CharacterVisual.play_world`

玩家在世界地图行走、待机、进入战斗锁定时调用。

| 逻辑状态 `state` | 方向后缀 | 映射 key / 字段 | PNG 覆盖条件 | 无覆盖时 |
| --- | --- | --- | --- | --- |
| `idle` | `down/up/left/right` | `world_animation_map["idle_{方向}"]` | map 有 key 且 sprite_frames 有对应动画 | CHJ 待机组 |
| `walk` | 同上 | `world_animation_map["walk_{方向}"]` | 同上 | CHJ 行走组 |
| `battle` | 同上 | 见下方战斗待机优先级 | 同上 | CHJ 主文件**最后两个动画组**合并循环 |

**主世界战斗待机**（`state == "battle"`）PNG 优先级：

```text
1. world_animation_map["battle_{方向}"]  → sprite_frames 有该动画
2. world_battle_animation                → sprite_frames 有该动画
3. 否则 → CHJ 末两组
```

> 注意：主世界 walk/idle **不会**因 map 里只配了 idle 就自动覆盖 walk；walk 必须在 map 里单独写 `walk_{方向}`。

### 2.2 战斗场景 `BattleUnit`

| 场景 | 解析方法 | PNG 优先级 | 无 PNG 时 |
| --- | --- | --- | --- |
| 战斗待机 | `get_battle_idle_png_override()` | ① `world_battle_animation` ② `default_animation` | CHJ 末两组 |
| 普攻/技能/追击等 | `get_battle_action_png_override(name)` | `animation_map` + sprite_frames | 见下方攻击类 CHJ |
| 受击/治疗/死亡等 | 同上 | sprite_frames 有则 PNG | `AnimationPlayer` 内置占位动画 |

**攻击类动作**（无 PNG 时尝试技能 CHJ）：

`普攻`、`技能`、`自动`、`追击`、`反击`

→ 播放 `chj_skill_path` 指向的 CHJ **第 0 组**，播完回到战斗待机。

### 2.3 纯 PNG 模式（无 CHJ）

与改造前一致：`world_animation_map` 解析全部世界动画；战斗走 `sprite_frames` + `animation_map`。

`resolve_world_animation` 在 walk 缺少专用帧时会回退到同朝向 idle（仅纯 PNG 模式使用此解析路径）。

### 2.4 规则速查表

```
动画类型                 映射 / 字段                           无 PNG 时
────────────────────────────────────────────────────────────────────────
世界 idle                world_animation_map idle_{方向}        CHJ 待机组
世界 walk                world_animation_map walk_{方向}        CHJ 行走组
世界战斗锁定 battle      world_battle_animation / battle_{方向} CHJ 末两组
战斗场景待机             world_battle_animation / default     CHJ 末两组
普攻/技能/追击/反击      animation_map + sprite_frames          chj_skill_path 第 0 组
受击/治疗/死亡等         animation_map + sprite_frames          内置占位动画
```

## 3. 新建形象与动画帧

### 3.1 目录约定

```text
client/asset/chj/
  {skin_id}.chj                 # 约定主 CHJ（chj_path 留空时自动找）
  {skin_id}_skill.chj           # 约定技能 CHJ（chj_skill_path 留空时自动找）
  2057.chj                      # 也可按原始编号命名，需在 .tres 显式写路径

client/resources/battle/unit_skins/
  人物/某形象.tres
  怪物/某怪物.tres
  其他/某形象.tres
```

### 3.2 新建纯 PNG 形象（无 CHJ）

适用：已有横条 PNG，四方向 idle/walk + 战斗动画齐全。

1. 在 Godot 中新建 `Resource` → 脚本选 `UnitSkin`
2. 设置 `skin_id`（与服务端 / 数据库一致）
3. 在 Inspector 中编辑 `sprite_frames`：为每个动画添加 `AtlasTexture` 帧
4. 填写 `world_animation_map`（见 §4.8）
5. 填写 `animation_map`、`default_animation`（战斗用）
6. 保存到 `unit_skins/` 对应子目录，文件名建议与 `skin_id` 一致

参考：`client/resources/battle/unit_skins/人物/初始形象男_001.tres`

### 3.3 新建 CHJ 主形象

适用：有原版 `.chj`，行走/待机满意，战斗待机或部分动作想自己补。

1. 将 `.chj` 放入 `client/asset/chj/`
2. 新建 `UnitSkin`，设置 `skin_id`
3. 设置 `chj_path`（或依赖约定路径 `{skin_id}.chj`）
4. 按需调整 `chj_display_scale`、`chj_walk_anim_speed` 等
5. **仅**在 `sprite_frames` 中制作需要替换的动画（如「战斗待机」）
6. 用 `world_battle_animation` 或 `world_animation_map` 指向这些动画名
7. 需要技能 CHJ 时，另放 `{skin_id}_skill.chj` 并设置 `chj_skill_path`

参考：`client/resources/battle/unit_skins/其他/CHJ测试_2057.tres`

### 3.4 在 sprite_frames 中新建一条 PNG 动画

在 Godot 编辑器中打开 `.tres` → 展开 `sprite_frames`：

| 步骤 | 操作 |
| --- | --- |
| 1 | 点击「添加动画」，命名（如 `战斗待机`） |
| 2 | 设置 `speed`（帧率，如 `4.0`） |
| 3 | 勾选/取消 `loop`（待机 true，技能 false） |
| 4 | 为每帧添加 `AtlasTexture`：`atlas` 指向 PNG，`region` 裁切单帧区域 |
| 5 | 在 `world_animation_map` / `world_battle_animation` / `animation_map` 中引用该动画名 |

**动画名必须与映射 value 完全一致**（区分大小写）。

### 3.5 新建技能 CHJ

1. 准备只含技能动作的 `.chj` 文件（通常第 0 组为技能序列）
2. 放到 `client/asset/chj/`，命名为 `{skin_id}_skill.chj` 或在 `chj_skill_path` 显式指定
3. 若某技能要用 PNG 而非 CHJ，在 `sprite_frames` 做该动画并在 `animation_map` 映射

当前限制：**技能 CHJ 固定播放第 0 组**，暂不支持按技能 ID 选组。

### 3.6 服务端关联

客户端 `skin_id` 需与数据库一致，例如：

```sql
UPDATE player SET skin_id = 'CHJ测试_2057' WHERE ...;
```

无需改协议；CHJ/PNG 组合 purely 客户端资源配置。

## 4. UnitSkin 参数说明

资源路径：`client/scripts/feature/battle/resources/unit_skin.gd`  
所有 `.tres` 形象均使用该脚本。

### 4.1 标识

#### `skin_id`（String，必填）

形象唯一 ID，与服务端 `player.skin_id`、宠物/怪物 `skin_id` 一致。

```text
skin_id = "初始形象男_001"
skin_id = "CHJ测试_2057"
```

加载方式：`CharacterSkinRegistry` 扫描 `client/resources/battle/unit_skins/` 递归匹配 `skin_id`。

---

### 4.2 动画 · `sprite_frames`（SpriteFrames）

PNG 序列帧集合。CHJ 模式下**仅用于局部覆盖**；纯 PNG 模式下驱动全部动画。

| 模式 | 用法 |
| --- | --- |
| 纯 PNG | 配齐 idle/walk/战斗/普攻等全部动画 |
| CHJ + 局部覆盖 | **只配**你想替换 CHJ 的动画，不必配 walk/idle |

示例（只替换战斗待机）：

```text
sprite_frames = 仅含动画「战斗待机」（2 帧循环）
world_battle_animation = "战斗待机"
# 不配 idle_down / walk_down → 行走与日常待机仍走 CHJ
```

---

### 4.3 战斗动画

#### `default_animation`（String，默认 `"待机"`）

战斗场景（`BattleUnit`）待机动画名；**CHJ 混合模式下优先用 `world_battle_animation` 覆盖战斗待机**。

| 模式 | 行为 |
| --- | --- |
| 纯 PNG | 进入战斗后播放该动画 |
| CHJ + 覆盖 | 若 `sprite_frames` 有该动画且 `get_battle_idle_png_override` 命中，用于战斗待机 |

```text
default_animation = "战斗待机"
```

> **注意**：CHJ 混合形象请用 `world_battle_animation` 指定战斗待机 PNG，**不要**把 `default_animation` 也设成「战斗待机」——旧版逻辑可能让普攻误匹配到待机动画。普攻/技能 PNG 覆盖请走 `animation_map`。

#### `animation_map`（Dictionary）

逻辑动作名 → `sprite_frames` 内动画名。用于战斗普攻、技能及 PNG 覆盖解析。

```text
animation_map = {
  "普攻": "普攻",
  "技能": "技能",
  "刃光斩": "普攻",    # 技能 ID 映射到同一套 PNG
}
```

CHJ 模式下：映射目标在 `sprite_frames` 中存在 → 播 PNG；否则攻击类走 `chj_skill_path`。

#### `animation_flip_h`（Dictionary）

按**动画名**（非逻辑名）控制 `AnimatedSprite2D.flip_h`。

```text
animation_flip_h = {
  "战斗待机": true,
  "普攻": false,
}
```

仅影响 PNG 播放；CHJ 翻转由帧号 ≥128 或右方向 `force_flip` 控制。

---

### 4.4 CHJ 世界渲染

#### `chj_path`（String，`.chj` 文件）

主 CHJ 路径。留空时自动尝试：

```text
res://asset/chj/{skin_id}.chj
```

```text
chj_path = "res://asset/chj/2057.chj"
chj_path = ""   # 使用约定路径或纯 PNG
```

#### `chj_display_scale`（Vector2，默认 `(2, 2)`）

CHJ 显示缩放，独立于 `sprite_scale`。

```text
chj_display_scale = Vector2(2, 2)   # 原版 16px 帧放大到 32px
chj_display_scale = Vector2(1, 1)   # 不放大
```

#### `chj_walk_anim_speed`（float，默认 `120`）

CHJ 行走动画 tick 倍率，越大切帧越快。

```text
chj_walk_anim_speed = 120.0
chj_walk_anim_speed = 80.0    # 更慢
```

#### `chj_idle_anim_speed`（float，默认 `60`）

CHJ 待机 / 战斗待机（末两组）tick 倍率。

```text
chj_idle_anim_speed = 60.0
```

#### `chj_frame_divisor`（float，默认 `8`）

取帧公式：`cursor = floor(tick / chj_frame_divisor) % frames.size()`

```text
chj_frame_divisor = 8.0
```

#### `chj_skill_path`（String，`.chj` 文件）

技能/普攻专用 CHJ。留空时自动尝试：

```text
res://asset/chj/{skin_id}_skill.chj
```

播放规则：第 **0** 组、播完一次后回到战斗待机。

```text
chj_skill_path = "res://asset/chj/CHJ测试_2057_skill.chj"
```

---

### 4.5 世界动画

#### `world_animation_map`（Dictionary）

主世界状态 + 朝向 → `sprite_frames` 动画名。

**Key 格式**：`{state}_{direction}`

| Key 示例 | 含义 |
| --- | --- |
| `idle_down` | 面向下待机 |
| `walk_left` | 向左走 |
| `battle_up` | 战斗锁定且面向上（PNG 覆盖用） |

**Value**：`sprite_frames` 里的动画名（必须存在才覆盖 CHJ）。

```text
world_animation_map = {
  "idle_down": "待机下",
  "idle_up": "待机上",
  "idle_left": "待机左",
  "idle_right": "待机右",
  "walk_down": "向下走",
  "walk_left": "向左走",
  "walk_right": "向右走",
  "walk_up": "向上走",
  "battle_down": "战斗待机",
}
```

纯 PNG 形象通常配齐 8 个 idle/walk；CHJ 形象**只写需要替换的 key**。

#### `world_battle_animation`（String）

主世界战斗锁定 + 战斗场景待机的 PNG 覆盖动画名（需在 `sprite_frames` 中存在）。

优先级（战斗待机 PNG）：高于 CHJ 末两组，低于 `battle_{方向}` map（若存在）。

```text
world_battle_animation = "战斗待机"
```

---

### 4.6 外观与碰撞

#### `world_collision_offset`（Vector2）

世界场景碰撞圆相对脚底锚点的微调。

```text
world_collision_offset = Vector2(0, 0)
world_collision_offset = Vector2(2, -4)
```

#### `sprite_offset`（Vector2）

PNG 脚底对齐后的微调；CHJ 渲染同样读取此字段。

```text
sprite_offset = Vector2(-13, 7)
```

#### `sprite_scale`（Vector2，默认 `(1.6, 1.6)`）

**PNG** `AnimatedSprite2D` 缩放；不影响 CHJ（CHJ 用 `chj_display_scale`）。

```text
sprite_scale = Vector2(1, 1)
```

#### `status_offset`（Vector2）

战斗场景血条/状态图标相对单位偏移。

```text
status_offset = Vector2(-90, -118)
```

#### `tint`（Color）

整体染色。`Color.WHITE` 表示不染色。

```text
tint = Color(1, 1, 1, 1)
```

## 5. 配置示例

### 5.1 纯 PNG（传统形象）

```text
skin_id = "初始形象男_001"
sprite_frames = [待机下, 待机上, 待机左, 待机右, 向下走, ... 战斗待机, 普攻, 技能]
default_animation = "战斗待机"
world_battle_animation = "战斗待机"
world_animation_map = { idle_down→待机下, walk_down→向下走, ... 共 8 方向 }
animation_map = { "普攻": "普攻", "技能": "技能", "刃光斩": "普攻" }
animation_flip_h = { "战斗待机": true }
sprite_offset = Vector2(-13, 7)
```

文件参考：`client/resources/battle/unit_skins/人物/初始形象男_001.tres`

---

### 5.2 CHJ 全量（无 PNG 覆盖）

```text
skin_id = "某CHJ形象"
chj_path = "res://asset/chj/647.chj"
chj_skill_path = "res://asset/chj/647_skill.chj"
chj_display_scale = Vector2(2, 2)
# 不配置 sprite_frames
# 不配置 world_animation_map
```

行为：walk/idle/battle 全 CHJ；普攻/技能走技能 CHJ。

---

### 5.3 CHJ + 只换战斗待机（最常见）

```text
skin_id = "CHJ测试_2057"
chj_path = "res://asset/chj/2057.chj"
chj_skill_path = "res://asset/chj/CHJ测试_2057_skill.chj"
chj_display_scale = Vector2(1, 1)
sprite_frames = 仅「战斗待机」2 帧
world_battle_animation = "战斗待机"
```

行为：

- 走路、日常待机 → CHJ
- 世界战斗锁定 / 战斗场景待机 → PNG「战斗待机」
- 普攻/技能 → 技能 CHJ（除非 sprite_frames 里有对应 PNG）

文件参考：`client/resources/battle/unit_skins/其他/CHJ测试_2057.tres`

---

### 5.4 CHJ + 换战斗待机 + 换向下走

```text
chj_path = "res://asset/chj/2057.chj"
sprite_frames = ["战斗待机", "自定义向下走"]
world_battle_animation = "战斗待机"
world_animation_map = {
  "walk_down": "自定义向下走",
}
```

行为：仅 `walk_down` 与 battle 用 PNG；其他方向 walk/idle 仍 CHJ。

---

### 5.5 CHJ + 普攻 PNG、技能 CHJ

```text
chj_path = "res://asset/chj/2057.chj"
chj_skill_path = "res://asset/chj/xxx_skill.chj"
sprite_frames = ["战斗待机", "普攻"]
world_battle_animation = "战斗待机"
animation_map = {
  "普攻": "普攻",
  "技能": "技能",
}
```

行为：

- 「普攻」→ PNG（sprite_frames 有）
- 「技能」→ sprite_frames 无「技能」→ 走 `chj_skill_path` 第 0 组

## 6. CHJ 主文件动画组（内置，无需配置）

主 CHJ 四方向行走/待机由代码硬编码映射：

| 方向 | 待机组 | 行走组 | 备注 |
| --- | --- | --- | --- |
| down | 0 | 1 | |
| up | 2 | 3 | |
| left | 4 | 5 | |
| right | 4 | 5 | 自动 `flip_h` |

战斗待机（无 PNG 覆盖）：**最后两个动画组**帧序列合并循环。

帧号 ≥ `128` 表示水平翻转绘制。详见 `docs/chj_sprite_web_control.md`。

## 7. 常见问题

### Q：普攻/技能播放时闪一下「战斗待机」PNG？

1. 确认 `sprite_frames` 里**没有**把「战斗待机」写进 `animation_map` 的「普攻/技能」映射  
2. CHJ 混合形象战斗待机只用 `world_battle_animation`，不要同时设 `default_animation = "战斗待机"`  
3. 普攻/技能无 PNG 时应走 `chj_skill_path`；占位文件若是主 CHJ 副本，看起来会像走路/待机而非攻击

### Q：sprite_frames 里做了动画，但没生效？

检查是否在 `world_animation_map` / `world_battle_animation` / `animation_map` 里**指名**；CHJ 模式不会自动扫描 sprite_frames 里有哪些动画。

### Q：只想换战斗待机，要不要配 idle/walk？

不需要。不配 `idle_*` / `walk_*` 即继续 CHJ。

### Q：纯 PNG 形象要不要配 chj_path？

不要配。留空即可，整个形象走 `sprite_frames`。

### Q：CHJ 和 PNG 缩放不一致怎么办？

分别调 `chj_display_scale`（CHJ）和 `sprite_scale`（PNG）。

### Q：技能 CHJ 能指定第几组？

当前固定第 0 组；多技能分组需后续扩展。

### Q：无 skin_id 的玩家用什么？

`player.tscn` Legacy（`AnimationPlayer` + 单 PNG hframes），与本指南无关。

## 8. 检查清单

发布前逐项确认：

- [ ] `skin_id` 与服务端 / 数据库一致
- [ ] CHJ 文件路径存在且可 `FileAccess.file_exists`
- [ ] 每个 PNG 覆盖动画都在 `sprite_frames` 中存在
- [ ] 每个 PNG 覆盖动画都有对应 map 字段
- [ ] 技能：PNG 或 `chj_skill_path` 至少一种可用
- [ ] 脚底对齐：`sprite_offset` / `chj_display_scale` 目视正常
- [ ] 纯 PNG 形象：`world_animation_map` 四方向 idle/walk 配齐
