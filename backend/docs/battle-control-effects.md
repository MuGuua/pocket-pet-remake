# 战斗控制效果双体系

服务端权威实现位于 `backend/server/internal/module/battle/control_formula.go`。

## 1. 概率系（无视抗性）

技能配置 `seal_chance_pct` / `control_chance_pct`（0~100）时：

- 直接按该百分比掷骰
- **不扣减**目标对应控制抗性
- 例：`seal_chance_pct = 50` → 固定 50% 封印概率

## 2. 威力系（对抗抗性）

技能配置 `seal_power` / `control_power`（> 0）时：

- 与目标对应控制抗性数值对抗（如 `seal_resist_pct`、混乱/睡眠/麻痹等抗性字段）
- **优先于概率字段**；二者同时填时只走威力系
- 公式（`diff = 威力 - 抗性`）：

| 条件 | 命中率 |
|------|--------|
| 抗性 ≥ 威力 | 0%（完全免疫） |
| diff ≥ 50 | 100%（稳控） |
| 0 < diff < 50 | `100% - (50 - diff) × 2%` |

示例（封印）：

- 350 威力 vs 350 抗性 → 0%
- 350 威力 vs 300 抗性（差 50）→ 100%
- 350 威力 vs 340 抗性（差 10）→ `100% - 40×2% = 20%`

## 3. 技能表字段

迁移 `061_skill_control_power.sql` 新增：

- `seal_power`：封印威力
- `control_power`：通用控制威力（配合 `control_status_id` 读取对应抗性）

## 4. 与其他状态的区别

流血、诅咒等非控制状态仍使用旧的「概率 − 抗性」折算（`adjustStatusChancePct`），与控制双体系无关。

## 5. 技能命中加成

迁移 `094_skill_hit_bonus.sql` 新增 `skill_hit_bonus`，用于配置“本次技能释放临时提高命中”的效果。

- 该值只参与本次技能命中/闪避判定：`最终闪避概率 = 目标闪避 - 施法者命中 - skill_hit_bonus`
- 不写回人物、宠物或战斗单位的基础命中属性，技能结算结束后自然回归正常
- 后台技能效果配置中选择“命中加成”，例如填 `40`，即表示本次技能按“施法者命中 + 40”参与计算
